Log masuk admin

Masukkan GitHub token anda untuk mengurus produk. Hanya pemilik token yang boleh menyimpan perubahan.

Bagaimana mendapatkan token?
  1. Buka GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Tekan Generate new token.
  3. Pada Repository access, pilih Only select repositories dan pilih repositori ini sahaja.
  4. Pada Permissions → Repository permissions, set Contents: Read and write.
  5. Tetapkan tarikh luput, kemudian salin token dan tampal di atas.

Token disimpan dalam pelayar anda sahaja dan hanya dihantar terus ke api.github.com. Jangan kongsi token dan jangan masukkan ke dalam repositori.
